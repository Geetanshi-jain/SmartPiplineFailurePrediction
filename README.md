# Smart Pipeline Failure Prediction System 🚰⚡

An AI-powered IoT analytics and predictive maintenance system developed for the **Water Works Department, Indore Municipal Corporation (जल प्रदाय विभाग, इंदौर नगर निगम)**. This platform simulates, predicts, visualizes, and alerts engineers about pipeline failures and water leakages across Indore.

> 🌐 **Live Demo:** [incandescent-horse-ee5418.netlify.app](https://incandescent-horse-ee5418.netlify.app)

---

## 🌟 Key Features

1. **Dual Machine Learning Engine:**
   * **Pressure Regressor (Random Forest):** Predicts hydraulic pressure deviations across line segments (`R² ~ 0.99`).
   * **Leakage Classifier (Random Forest):** Detects leakage likelihood with high accuracy, handling heavily imbalanced real-world telemetry distributions (`ROC-AUC ~ 0.99`).
2. **Interactive Bilingual Interface (English + Hindi):**
   * Instant toggle translations across charts, logs, control modals, forms, and legends.
3. **Advanced GIS Network Map:**
   * Built on **Leaflet.js** supporting street map layouts and satellite imagery terrain tiles (Esri Satellite).
   * Visual indicator lines mapping risk levels (Green: Safe, Orange: Warning, Red: Active Leak).
4. **Internalized SMTP & Email Alarms:**
   * Secure automated alerts dispatched to municipal authorities via Gmail SMTP with simplified UI configuration.
5. **PDF Reports & Analytics Summary:**
   * Professional PDF reports summarizing telemetry charts, spatial distribution plots, and priority maintenance actions.

## ⚙️ Technology Stack

* **Backend:** Python 3.12, Flask, Pandas, NumPy, Scikit-Learn, Joblib, ReportLab, Matplotlib
* **Frontend:** HTML5 (Semantic), Vanilla CSS, JavaScript (ES6+), Leaflet.js (GIS Map), Chart.js (Interactive Telemetry Charts)
* **Email System:** SMTP (via SSL/TLS)
* **Deployment:** Netlify (Static Frontend)

## 🚀 Installation & Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/<your-username>/smartPipelineFailurePrediction.git
   cd smartPipelineFailurePrediction
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *Note: Ensure packages like `flask`, `pandas`, `numpy`, `scikit-learn`, `joblib`, `matplotlib`, and `reportlab` are installed.*

3. **Configure Gmail SMTP Credentials:**
   Open `app.py` and set your Gmail account email and App Password:
   ```python
   INTERNAL_SMTP_USER = "your-email@gmail.com"
   INTERNAL_SMTP_PASS = "your-16-char-app-password"
   INTERNAL_SENDER_EMAIL = "your-email@gmail.com"
   ```

4. **Run Server Locally:**
   ```bash
   python app.py
   ```
   The application will boot up at `http://127.0.0.1:5000` or on your network IP `http://10.193.42.169:5000`.

## 📊 Model Training

To retrain the models on the updated datasets:
```bash
python model_training.py
```
This runs regression and classification scripts, displaying accuracy scoring plots and saving updated model serialization dumps as `pressure_model.pkl` and `leakage_model.pkl`.
